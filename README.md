# 🏛️ Virtual Society
Welcome to **Virtual Society** — a persistent economy bot where every
server is part of one connected world.

You work, earn, spend, save, and borrow. Servers have their own
treasuries. Everything flows into a shared global bank. It's a small
economy that lives across Discord.

---

## Start Here

Run these three commands the moment you join a server with Virtual Society:

1. `/balance` — see how much money you have
2. `/job-list` — look at available jobs
3. `/apply slot:1` — grab your first one

Then run `/work` every hour to earn. That's the core loop.
